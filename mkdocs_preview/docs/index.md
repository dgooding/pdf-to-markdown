# ITSD Service Desk

This GitHub Pages site provides a simple, searchable home for IT support documents.

## Services

- Convert PDF, DOCX, Markdown, and text files with GitHub Actions.
- Publish approved output through Git commits with full audit history.
- Browse and search published procedures, guides, and reference material.
